# Nestville EstateCRM - Organized MERN

## Apps
- Frontend CRM: http://localhost:5173
- Admin control center: http://localhost:5174
- Backend API: http://localhost:5000



## Start backend
```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

## Start frontend
```bash
cd frontend
npm install
npm run dev
```

## Start admin
```bash
cd admin
npm install
npm run dev
```

## Frontend structure
Each page is isolated under `frontend/src/pages/<PageName>/`, shared UI components are isolated under `frontend/src/components/`, and routing lives in `frontend/src/routes/`.

## Backend structure
Models, controllers, routes, middleware, config and utilities are separated.
